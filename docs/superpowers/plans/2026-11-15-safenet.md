# SafeNet Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Нативное приложение для строки меню macOS 13+, замораживающее выбранные программы при потере VPN или неразрешённом IP/стране и закрывающее их по истечении заданного времени.

**Architecture:** Логика (состояния, проверки, заморозка, конфиг) живёт в библиотеке `SafeNetCore` без UI и тестируется через протоколы `NetworkProbe`, `ProcessTable`, `Clock`. Поверх неё `SafeNetApp` (SwiftUI `MenuBarExtra` + окно панели) и режим CLI в том же бинарнике, общающийся с запущенным приложением по unix-сокету.

**Tech Stack:** Swift 5.8 (Command Line Tools, без Xcode), SwiftPM, SwiftUI (macOS 13 API), XCTest, Yams (YAML), `NWPathMonitor`/SystemConfiguration, `SMAppService`, `UserNotifications`.

**Spec:** `docs/superpowers/specs/2026-11-15-safenet-design.md`

## Global Constraints

- macOS 13 Ventura минимум, работает и на новейшей; проверка на macOS 13.7.8 Intel; универсальный бинарник x86_64 + arm64, arm64 проверяется только сборкой.
- Swift 5.8.1: без `@Observable` (только `ObservableObject`), старая форма `onChange(of:perform:)`, нет `openSettings` (панель — `Window(id:"panel")` + `openWindow`).
- Без прав администратора, без платных сервисов, без телеметрии и автообновления. Наружу только запросы IP-сервисам и `/cdn-cgi/trace` ИИ-сервисов.
- Рабочее название `SafeNet`; название, логотип и код Kordon не использовать.
- Состояния: `ок`, `заморожено`, `закрыто`, `пауза`. Неопределённость = заморозка. Оффлайн = заморозка без закрытия.
- Акцент по умолчанию синий; статусы всегда зелёный / оранжевый / красный независимо от акцента. Тема: `светлая | тёмная | как в системе` (по умолчанию «как в системе»).
- Параметры по умолчанию: `check_interval` 5 с, `min_agree` 2, срок заморозки (`grace`) 20 с, `close_timeout` 5 с, пауза 15 мин, маршрут ИИ раз в 120 с.
- Конфиг: `~/Library/Application Support/SafeNet/config.yaml`, источник истины, горячая перезагрузка, при ошибке уведомление и работа на старых настройках.
- Никогда не замораживать: сам SafeNet, `launchd`, `WindowServer`, Finder, Dock, `loginwindow`, пути `/System`, `/usr/libexec`, процессы других пользователей.
- Репозиторий: внутри `/Users/pref/Documents/SafeNet` выполнить собственный `git init` (родительский репозиторий находится на домашней папке, в него не коммитить).

## Review Focus

1. PID переиспользован после выхода замороженного приложения — `SIGCONT` не должен попасть в чужой процесс (сверять время запуска).
2. Ноутбук уснул во время заморозки — таймер закрытия не должен «истечь» за время сна; после пробуждения новая проверка и отсчёт заново.
3. `config.yaml` повреждён или правится на лету — работа на старых настройках, без падения и без потери защиты.
4. Все IP-сервисы вернули разные адреса или ни один не ответил при активной сети — заморозка, но не закрытие до полного срока.
5. Новый процесс защищаемого приложения запущен, пока оно уже в заморозке (хелпер, перезапуск) — он тоже замораживается.

## File Structure

```
Package.swift
Sources/SafeNetCore/
  Config/Config.swift            модель настроек, значения по умолчанию
  Config/ConfigStore.swift       чтение/запись YAML, горячая перезагрузка
  Engine/Verdict.swift           Verdict, PolicyInput, evaluate(...)  (чистая логика)
  Engine/Guard.swift             конечный автомат состояний и таймеры
  Net/IPChecker.swift            опрос N сервисов, кворум IP+страна
  Net/NetworkMonitor.swift       события сети, интерфейсы, прокси
  Net/TrustedNetworks.swift      MAC шлюза из ARP
  Net/Probes.swift               IPv6, DNS, маршрут ИИ (/cdn-cgi/trace)
  Procs/ProcessTable.swift       список процессов, сопоставление, deny-list
  Procs/Freezer.swift            SIGSTOP/SIGCONT, журнал PID, разморозка, страж
  Store/EventLog.swift           история и статистика (JSONL)
Sources/SafeNetApp/
  main.swift                     вход: CLI или приложение
  AppState.swift                 ObservableObject, связывает ядро и UI
  Theme.swift                    токены темы, акцент, плотность, шрифт
  MenuBarView.swift              окно из строки меню
  Panel/*.swift                  вкладки панели
  IPC.swift                      unix-сокет, команды CLI
Tests/SafeNetCoreTests/          тесты ядра
scripts/build-app.sh             сборка .app, ad-hoc подпись, универсальный бинарник
```
